# DMart Retail Sales Analytics Dashboard

## Project Overview
Built an interactive retail sales analytics dashboard using Excel, Pivot Tables, KPI Cards, Charts, Conditional Formatting, and business calculations.

## Features
- Sales Analysis
- Profit Analysis
- Customer Segment Insights
- Regional Performance Tracking
- Monthly Revenue Trends
- Interactive Dashboard Design

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Conditional Formatting
- Data Validation
- GitHub
